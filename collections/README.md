# Example API requests

Import the Chartly collection in Bruno and configure an environment variable named `api_key` with the key from **Settings → Developer API** in your local Chartly instance. Keep the value in a private environment. The checked-in collection uses a variable so the same requests can run against different instances.

The Python examples that use `CHARTLY_API_KEY` expect it in the shell environment. Use a demo or paper environment when trying an example that places orders.
