## Delivered implementation under review

The original Workspace, profile Connections and Settings → Connections & Data remain the UI base. Configuration is separate from observed account identity, freshness, permission and measured capability. The allowlisted read-only factory has no submit/cancel/protection dispatcher. Diagnostic observations are synthetic. A public response, configured account or restored record does not grant external execution authority.

The private registry and local vault use existing authenticated proof/CSRF, bounded workers, expected revisions and stable receipts. Credential writes encrypt directly before a worker-file payload could contain plaintext; reads/export return opaque metadata. Fetching occurs outside the write transaction. The service fences changed owner, revision, account identity, configuration and credential generation before publishing observations/cursor/journal facts and the receipt together.

Caller-side owner generations now protect account choices, catalog paging, wizard saves, IndexedDB publication and shared CSRF/mutation paths. `X-Chartly-Principal` is an optional expected-authenticated-owner precondition, not an identity selector or replacement for cookie authentication/CSRF. A mismatch refuses the operation before mutation. These guards and exact native symbol/timeframe preservation are included in the frozen frontend selection; root's final browser/API verification remains controlling.

Confirmed fully closed normalized trade observations alone can project into the linked account's P03 book. Raw deals, transfers, partial fills and unknown submissions remain observations. Financial corrections retain earlier versions and require review of the retained preview. Missing pages do not delete cached facts. Native pagination retains its exact overall request window while actual page coverage can be smaller; final native cursor consumption does not invent UTC coverage.

Workspace backup/restore/Undo includes the installed `connectors` module, excludes the vault and clears usable credentials/active linkage. Owner-confirmed restore rebinds local scope while retaining observations, receipts and provenance. Reverify and explicitly relink before more reads. [Storage, history and recovery contract](HISTORY_STORAGE_RECOVERY.md).

The user-directed creation changes use one **New profile** entry, optional multiple/custom session tags and strategy labels, an explicit timezone unaffected by tags, and positive exact per-run default capital. Replay creation requires actual owned nonempty history and a reviewed currency/source/version first; import return preserves the owner-scoped non-secret draft. Native symbol spelling and interval are retained. Each run still reviews its own paper economics. Current fixed-cost/one-times collateral support and the separate [cost/leverage extension proposal](REPLAY_COST_AND_LEVERAGE_EXTENSION.md) are presented honestly.
