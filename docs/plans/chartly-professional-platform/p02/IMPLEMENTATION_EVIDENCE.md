## Supported scope and remaining limits

This package certifies file-backed local SQLite on the tested Windows/Python runtime and the supported Node production build. Common NullPool/WAL/cooperative SQLite and eventlet/gthread design is preserved; CI includes the new tests. **No unrun Linux gunicorn or PostgreSQL workspace certification is claimed.** PostgreSQL workspace URLs are rejected. The separate User UID migration has a PostgreSQL branch without a local PostgreSQL fixture.

The registry covers the actual implemented workspace modules, not an entire installation image. Market-data bars, credentials, installed code, runtime activation and unscoped legacy stores are explicitly excluded. Aggregate bounds and structured oversized-export failures are documented; data stays intact. Date-only times, binary-number precision and declared provider identity stay raw/unverified. Canonical accounting, statement import, source reconciliation, deterministic paper execution, provider/feed access and professional research remain their owning packages.
