# Security

If private vulnerability reporting is enabled on the GitHub repository, use **Security → Report a vulnerability**. Otherwise use a private contact you already have for the maintainers. Share a short description, the version or commit, and steps to reproduce with synthetic data. Keep credentials, account identifiers, real order records, and exploit details out of public issues.

For local use, keep the app bound to localhost unless you have configured the access controls for a networked deployment. Keep model provider credentials, broker credentials, and Chartly Developer API keys private and rotate any key that has been exposed. Review automation and Agent tool permissions before connecting accounts with order execution access. Use saved data or an isolated demo account for first checks.
