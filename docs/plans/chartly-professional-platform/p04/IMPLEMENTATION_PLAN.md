3. **T04 immutable data.** Principal-scoped logical dataset keys include source, instrument, native interval, price basis/adjustment and frozen calendar. Every publication produces an immutable version/checksum; keep/replace policies merge against an identified base without changing it, and new-version creates a fresh uploaded snapshot. Current catalog revisions and stable receipts guard stale/repeated actions. DuckDB candle files remain private and are not written into the mutable legacy global history database. Root owns metadata, transactions, file publication and local APIs.
4. **T05 time/calendar.** Store UTC microseconds with explicit IANA/session snapshot. Native bars are queried by UTC instant bounds; no host-local conversion, fixed-IST anchoring, synthetic filling or implicit resampling. Unknown calendars label gap classification as unknown. 5. **T06 connected screens.** Catalog/detail shows exact source/version/native resolution, coverage, quality, local size and archived/in-use state. Open chart pins version/checksum and preserves return context. Practice handoff creates or pre-fills only a Draft with explicit version identity; P06 still owns validated simulation/run execution. The existing chart interface remains the base.
6. **T07 downloads.** Existing global Historify provider jobs cannot safely be relabelled private: they mutate shared bars, use process-local quotas and cannot resume scoped checkpoints after restart. Implement a separately scoped finite download lifecycle that explicitly binds the current principal's credential/source, persists chunk/quota/retry/cancellation state, and sends fetched rows through the same quality/version publication path. Reuse the provider history fetch adapter only. No live provider call or provider certification is inferred from fixture tests; unavailable provider capability stays visible. Independent audit supplies adversarial lifecycle tests.
7. **T08 retention/recovery.** Archive/restore metadata retains immutable bytes and exact references. Check saved practice references and keep direct version reads available; no permanent purge is introduced. Provide a separate checksummed dataset bundle/restore flow and export manifest links. P02 workspace ZIPs continue to disclose that candle files are separate; do not imply that a journal backup contains history files. Verify restore/checksum failure and referenced-version protection.

## Frozen service and UI boundary

The local API prefix is `/api/local/v1/datasets`, protected by existing verified local proof, CSRF and bounded request/worker rules. Ownership is always the server principal. It does not require an active migrated browser source for catalog/import/chart operations. SQLite metadata uses the existing local database connection conventions; DuckDB files are separately scoped immutable content, opened/closed inside bounded first-party worker operations.

- `GET /` → `{revision,versions,jobs,capabilities}`. A version has `{id,datasetId,name,metadata,checksum,sourceHash,rowCount,start,end,sizeBytes,quality,coverage,createdAt,archivedAt?,dependencies}`. `start/end` are UTC seconds and metadata includes provider/symbol/exchange/interval/priceBasis/adjustment/volumeMeaning/currency/calendar/allowNegativePrices.
- `GET /versions/:id` → version/detail; `GET /versions/:id/bars?from=&to=&limit=` → `{versionId,checksum,bars}`. Bounds are UTC seconds; bars use timestamp numeric seconds plus exact OHLC/volume strings/null. Native interval only.
- `POST /imports/preview` takes `{expectedRevision,csvText,mapping,context,baseVersionId?}` → `{id,expectedRevision,status,preview}`. The pure normalizer returns rows/counts/coverage/quality, canonical sorted bars and source/content hashes.
- `GET /imports/:id` resumes retained source review. `POST /imports/:id/repreview` takes `{expectedRevision}` and stages a fresh current preview. `POST /imports/:id/commit` takes `{expectedRevision,requestId,policy,allowRejectedRows}` → committed `{version,catalog}`. Policy is `keep`, `replace` or `new-version`; existing bytes never change.
- `POST /versions/:id/archive|restore` takes `{expectedRevision,requestId}` → `{version,catalog}`. `GET /versions/:id/export?format=csv|bundle` returns an actual file; bundle contains explicit format/version, manifest, checksums and data. Dataset bundle restore has a separate validated preview and commit.
- Download job request/status/pause/cancel/resume/retry uses explicit job IDs and persisted state. Its exact certified adapter scope is recorded before T07 is checked off.

UI owns the new typed local client and focused library/import/detail surfaces within existing Historify chrome, private exact-version chart mode, route placement and practice draft context. Root owns Python services/blueprints/schema, worker dispatch, recovery integration, shared DB types and acceptance. Quality owns its pure parser/tests/policy. Writes to accepted P03 files need compatibility regression evidence; historical gate evidence remains intact.
